# ETHSWAP V9.3-Innovation 策略运行规则详解

本文档整理了当前系统（2026-03-24 优化版）的核心运行逻辑，供日常维护和参数调整参考。

## 一、 网格计算规则 (3实体 + 2虚拟层)

### 1. 数据采集
- **回测数据**：使用最近 **6 小时**（360 根 1 分钟线）的 OHLC 数据。
- **5高5低选取**：从 360 根 K 线中提取 **5 个最高价** 和 **5 个最低价**。

### 2. 去极值算法 (去针)
- **网格顶 (grid_top)**：将 5 个最高价排序，**剔除绝对最大值**，取剩余 4 个值的平均。
- **网格底 (grid_bottom)**：将 5 个最低价排序，**剔除绝对最小值**，取剩余 4 个值的平均。
- **目的**：有效防止单根异常插针带偏网格线，使网格紧贴实体交易区。

### 3. 五层空间布局
- **步长 (Step)**：`(grid_top - grid_bottom) / 3`
- **极高线**：`grid_top + Step` (虚拟观察边界)
- **P3 (实体顶)**：`grid_top`
- **P2 (中转界)**：`grid_bottom + 2 * Step`
- **P1 (底层顶)**：`grid_bottom + 1 * Step`
- **P0 (实体底)**：`grid_bottom`
- **极低线**：`grid_bottom - Step` (虚拟观察边界)

## 二、 网格重置触发机制

系统为了保证网格的“鲜活度”，会在以下三种情况强制重新计算网格：

1.  **每日定时重置**：UTC 时间 0 点（北京时间 08:00）后的第一次数据包触发。
2.  **周期性强制重置**：如果距离上次计算网格超过 **4 小时**，且价格在网格内平稳运行，也会触发刷新以适应最新的波动率。
3.  **突破重置**：如果价格突破 **极高线** 或 **极低线** 且在该区域停留超过 **2 小时**，系统认为趋势已改变，将更新震荡区间。

## 三、 下单与入场机制

### 1. 实体层入场位
- **做多区域 (Layer 0)**：价格在 `[P0, P1]` 之间，且处于该区间 **下半部**（靠近 P0）。
- **做空区域 (Layer 2)**：价格在 `[P2, P3]` 之间，且处于该区间 **上半部**（靠近 P3）。

### 2. RSI 趋势过滤
- **买入条件**：当价格处于做多区域，且 `RSI < 25` (超卖加重) 或处于低位反弹时触发。
- **卖出条件**：当价格处于做空区域，且 `RSI > 85` (超买严重) 或处于高位回落时触发。
- **动态阈值**：RSI 阈值会根据市场波动自动在 `[25, 35]` (买入) 和 `[65, 85]` (卖出) 之间微调。

### 3. 风控与杠杆
- **动态杠杆**：初始 **1x**，随着层数增加可逐步提升至 **3x**。
- **Kelly 仓位管理**：根据历史胜率自动计算单笔下单金额。
- **交易冷却**：两次下单之间至少间隔 **60 秒**，防止重复刷单。

## 四、 系统运行参数 (实时跳动优化)

### 1. 响应与轮询
- **数据轮询间隔**：**1.0 秒** (2026-03-24 从 2.0s 优化，显著提升跳动感)。
- **API 超时控制**：单次请求超时 10s，失败会自动在 1s 后重试。

### 2. 后台同步频率
- **账户资金余额单步同步**：每 **10 秒** 同步一次实盘余额。
- **历史成交记录同步**：每 **30 次** 数据轮询（约 30-45s）同步一次交易所历史记录，确保本地 PNL 曲线准确。
- **状态广播**：实时向 Dashboard 推送最新价格、仓位、RSI 和网格线。
