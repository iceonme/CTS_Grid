# ETHSWAP V9.3-Innovation 策略运行规则详解

本文档整理了当前系统（2026-03-24 优化版）的核心运行逻辑，供日常维护和参数调整参考。

## 一、 网格计算规则 (3实体 + 2虚拟层)

### 1. 数据采集与采样 (分段逻辑)
- **初始/0点数据**：使用最近 **6 小时**（360 根 1 分钟线）。
- **日内重置数据**：使用最近 **4 小时**（240 根 1 分钟线）。
- **5段采样**：将时间窗口均分为 **5 段**，取每段内的 **1个最高价** 和 **1个最低价**，共得 5 高 5 低。

### 2. 去极值算法 (去针)
- **网格顶 (grid_top)**：将 5 个最高价排序，**剔除绝对最大值**，取剩余 4 个值的平均。
- **网格底 (grid_bottom)**：将 5 个最低价排序，**剔除绝对最小值**，取剩余 4 个值的平均。
- **目的**：有效防止单根异常插针带偏网格线，使网格紧贴实体活跃区。

### 3. 五层空间布局 (6条线)
- **步长 (Step)**：`(grid_top - grid_bottom) / 3`
- **极高线 (VH)**：`grid_top + Step` (突破观察边界)
- **P3 (实体顶)**：`grid_top`
- **P2 (中转界)**
- **P1 (分界线)**
- **P0 (实体底)**：`grid_bottom`
- **极低线 (VL)**：`grid_bottom - Step` (突破观察边界)

## 二、 网格重置触发机制

1.  **配额恢复**：每日 **北京时间 00:00** 准时恢复每日重置配额为 **2 次**（不强制重刷网格数据）。
2.  **突破观察**：若价格突破 **极高线 (VH)** 或 **极低线 (VL)**，开启 **2 小时** 观察期。
3.  **执行重置**：
    - 若 2 小时后价格仍未回归网格，且当日 **2次配额** 未用完，则触发重置。
    - 使用 **最近 4 小时** 数据重新计算网格。
    - **持仓处理**：重置时现有持仓**保留原样**，不强制平仓。

## 三、 下单与入场机制 (RSI 详细逻辑)

### 1. 入场位置要求
- **做多 (Long)**：价格处于 **Layer 0** (`[P0, P1]`) 且位于该层 **下半部**。
- **做空 (Short)**：价格处于 **Layer 2** (`[P2, P3]`) 且位于该层 **上半部**。

### 2. RSI 触发阈值
系统根据趋势强度（LSTM/ATR）动态调整 RSI 阈值：

| 动作 | 弱趋势/震荡 (默认) | 强趋势 (放宽/顺势) |
| :--- | :--- | :--- |
| **做多入场** | RSI <= **25** | RSI <= **30** |
| **做空入场** | RSI >= **85** | RSI >= **80** |
| **平多止盈** | RSI >= **70** | RSI >= **65** |
| **平空止盈** | RSI <= **40** | RSI <= **45** |

### 3. 风控与执行
- **仓位管理**：单笔基础仓位 0.2x 杠杆（顺势时加倍至 0.4x）。
- **交易冷却**：两次下单之间至少间隔 **60 秒**。
- **动态杠杆**：全局杠杆 1x-3x 自适应。
