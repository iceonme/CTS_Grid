# CTA2 协作工作区 (Workspace)

这里是人类与 AI 进行深度协作、任务跟踪及灵感记录的专属区域。

## 目录索引

### 🧠 [AI-brain](./AI-brain/)
存储 AI 的核心认知、记忆以及对项目的全局分析。
- **[MEMORY.md](./AI-brain/MEMORY.md)**: 项目灵魂与长期记忆库，记录核心原则与重大决策。
- **[MEM001-AgentsThinking-2026-03-15.md](./AI-brain/MEM001-AgentsThinking-2026-03-15.md)**: AI 的核心系统认知基石。

### 🏎️ [ats.py](../ats.py)
**系统总线控制平面**。唯一且标准化的 Agent Friendly 命令行入口。
- 使用 `python ats.py run <skill>` 启动策略。

### ⚖️ [adr](./adr/)
**架构决策记录 (Architecture Decision Records)**。存储最终确定的、开发必须遵守的技术决策与规范。
- 遵循 `ADR[ID]-[名称]-[日期].md`规范。

### 📋 [task](./task/)
存储当前的开发任务、待办列表及历史 Walkthrough。
- `history/`: 历史变更记录。
- **[TASK001-Restructuring-2026-03-15.md](./task/TASK001-Restructuring-2026-03-15.md)**: 当前文档系统重构任务详情。

### 💡 [insights](./insights/)
存储对特定策略逻辑、数据模式或市场观测的深度分析。
- 遵循 `INS[ID]-[名称]-[日期].md` 规范。

---

> 注：如需查看正式的技术规范或架构哲学，请访问外层 [docs/](../docs/README.md) 目录。
